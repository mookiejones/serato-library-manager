# Keyboard shortcuts

The keys below work anywhere on the library screen, except while you are typing in a field. **Esc** still closes a dialog or clears a search.

**Shortcuts**, at the bottom of the sidebar, opens this list. **?** opens it too.

Rest the pointer on any control, or reach it with Tab, and a short note says what it does. If the control has a shortcut, the note shows the keys. Esc or any other key hides the note.

| Key | Action |
| --- | --- |
| Ctrl+F or Command+F, or / | Focus search in the current view |
| Ctrl+K or Command+K | Find a track or a file |
| Up or Down | Move through the list |
| Enter | Open the row |
| Ctrl+1 or Command+1 | Library, which is all tracks |
| Ctrl+2 or Command+2 | Crates |
| Ctrl+3 or Command+3 | Files |
| Ctrl+4 or Command+4 | History |
| Ctrl+5 or Command+5 | Snapshots |
| Esc | Close a dialog, or clear the search |
| ? | Show this list |
| Space | Play or pause |
| Left | Back 5 seconds |
| Right | Forward 5 seconds |

On Windows the key with the command is Ctrl. On a Mac it is Command. Both are listed in the app as Ctrl/Cmd.

Space plays or pauses. Left moves 5 seconds back. Right moves 5 seconds forward. They do not change the library.

## Find a track or a file

Ctrl+K or Command+K opens **Find a track or file**.

1. Type a name. A few letters are enough. Each word has to appear in the name, or in the folder name.
2. Tracks from the open library show at once. Files on disk follow. A file row says **File**. A track row says **Track**.
3. Use Up and Down to move. Enter opens that row. A track opens in the library. A file opens in **Files**, in its folder.
4. Esc closes the box and leaves the search behind it as it was.

If the disk search cannot be read, the box says so and keeps the track matches. **Try again** asks for the files again.

**Search tracks** and **Search files** are still there. `/` or Ctrl+F focuses the one for the view you are in. Snapshots has no search field. `/` there tells you to use Ctrl+K.

## Lists

Up and Down move the highlight. Enter opens it.

In **Crates**, the crate list keeps its own keys when that list is focused. Right opens a crate. Left closes it. Those keys are not the seek keys while the crate list has focus.

In **Files**, Up and Down move through the folder. Enter opens a folder or ticks a file.

In **Snapshots**, Up and Down move through the saved copies. Enter opens **Review restore**. Nothing is written until you confirm that dialog.
