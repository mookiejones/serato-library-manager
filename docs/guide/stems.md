# Stems

**Stems** lists tracks Serato has given a stems analysis state in the current space. The note says **Tracks with a stems analysis state.**

A matching row shows the word **stems**.

This view does not create stems, and it does not separate the drums, bass, melody, or vocal. Open the track and use the same details as any other track. [Track details](tags.md) covers save, reveal, Prepare, and relocate.

A track with no stems analysis state does not appear here. It is still in **Crates**.
