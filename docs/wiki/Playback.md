# Playback

Play a track that is already in the library. The sound stays on this computer.

Double-click a row, or click **Play**. The bar under the list shows the title, the artist, pause, a seek bar, and volume.

**Space** pauses and resumes, unless you are typing.

Playback does not change the audio file and does not add a history row. If the window cannot play the file, the bar says **This file cannot be played in this window.**

Music that lives behind a shortcut folder still plays, including when that folder points at another disk. A shortcut that points at a file outside the folder named in the library does not.
